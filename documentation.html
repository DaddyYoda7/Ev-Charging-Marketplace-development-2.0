1. Executive Summary & Core Mission

EV Connect AI is a full-stack, two-sided electric mobility marketplace and telemetry management platform engineered to resolve the most critical bottlenecks in India's rapid EV adoption: charger availability fragmentation, range anxiety, dynamic time-of-day tariffs, and hardware unreliability.

The architecture unifies three primary stakeholder workflows into a cohesive, low-latency, and high-security web ecosystem:

Stakeholder Persona Core Platform Capabilities Value Proposition & Impact
EV Drivers (2W / 4W) Pan-India discovery, 45-min slot reservation, vehicle garage manager, simulated UPI/Card payments, and AI Highway Trip Planner. Eliminates range anxiety, guarantees slot availability, and supports both 2W battery swaps and 4W Ultra-Fast DC charging.
Station Hosts / CPOs Station builder, bay hardware management (3.3kW to 350kW), dynamic kWh tariff editor, and automated 90% payout settlement. Maximizes charger utilization, enables dynamic peak-hour monetization, and automates revenue reconciliation.
Platform Admins National grid telemetry hub, 10% platform commission ledger, station verification audit, and predictive hardware failure monitoring. Provides total visibility over national EV infrastructure health, Gross Merchandise Value (GMV), and dispute management.
⚡ Pan-India Infrastructure Scope
The platform ships with pre-configured stations covering 14 key Indian metropolitan regions and expressways: Bengaluru, Mumbai, Delhi NCR, Hyderabad, Chennai, Pune, Ahmedabad, Kolkata, Jaipur, Kochi, Chandigarh, Lucknow, Goa, and the Mumbai-Pune Expressway.

4. Phased Development Roadmap (Phases 1 to 6)

Phase 1: User & EV Driver Platform

  • Multi-Role Switcher: Seamless switching between Driver (Cyan #00F2FE), Host (Emerald #00E676), and Admin (Purple #C084FC).
  • Interactive Garage Manager: Configurable EV garage profiles supporting Ather 450X, Ola S1 Pro, TVS iQube, Tata Nexon EV, MG ZS EV, and Hyundai Ioniq 5 with adjustable SoC sliders.
  • Pan-India Map Explorer: 15 verified stations across 14 cities with interactive city quick-jump shortcuts.
  • Search & Filter Grid: Real-time query search, vehicle category filters (All, 🛵 EV Scooty, 🚗 4W Fast DC), custom transparent frosted connector dropdown with full background blur, max tariff slider, and Open Bays toggle.

Phase 2: Station Owner / Host Marketplace

  • Station Onboarding Builder: Comprehensive registration form for physical hubs with GPS coordinates, address, and amenities (Café, Restrooms, WiFi, CCTV).
  • Bay Hardware Configurator: Add and configure individual chargers ranging from 3.3kW AC (15A socket) up to 350kW DC Ultra-Fast.
  • Dynamic Tariff & Penalty Engine: Set base tariffs (₹/kWh), peak-hour surcharges (1.25x), and idle parking penalties (₹/min after charging completion).

Phase 3: Slot Reservation & Conflict Prevention Engine

  • Dynamic 45-Minute Slot Matrix: Generates available slots for today and tomorrow based on station operational hours.
  • Atomic Concurrency Control: SQLite-level transaction checks prevent double-booking collisions by verifying slot overlaps before confirming reservations.
  • Session Lifecycle State Machine: Transitions through CONFIRMED → ACTIVE (charging in progress) → COMPLETED or CANCELLED.

Phase 4: Financial Transactions, Revenue Splits & Invoicing

  • Multi-Method Checkout: Simulated payment gateway supporting UPI QR codes (GPay, PhonePe, Paytm), Credit/Debit Cards, and EV Connect Digital Wallet.
  • 10/90 Settlement Engine: 
    Platform Commission (10%) = Total Amount * 0.10
Host Payout (90%)         = Total Amount * 0.90
  • Cryptographic GST Tax Invoices: Generates printable and downloadable tax invoices with HMAC-SHA256 verification hashes.

Phase 5: Multi-Factor AI Recommendation Engine

  • Mathematical Weighted Scoring Model: 
    Score = (0.30 * Availability) + (0.25 * Proximity) + (0.20 * Price) + (0.15 * Speed) + (0.10 * Rating)
  • Explainable AI (XAI) Badges: Displays natural language rationale tags (e.g. "Top Pick: 60kW Fast DC + 100% Green Solar").
  • AI Route & Battery Planner: Computes total trip distance, estimated energy consumption (kWh), remaining SoC at arrival, and recommends charging stops along major expressways.

Phase 6: OCPP 2.0.1 Hardware Simulator & Predictive Maintenance

  • OCPP Message Protocol: Implements BootNotification, StatusNotification, Heartbeat, MeterValues, StartTransaction, and StopTransaction.
  • Fault Injection Sandbox: Live simulation for Overheating, Ground Fault, and Connector Lock Failure.
  • Predictive Maintenance (MTBF): Evaluates voltage variance, connector wear cycles, and hardware temperature to calculate Mean Time Between Failures.

6. Database Schema & REST API Specifications

6.1 Database Relational Schema (SQLite3)

-- Users & Stakeholders
CREATE TABLE users (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    role TEXT CHECK(role IN ('DRIVER', 'HOST', 'ADMIN')),
    wallet_balance REAL DEFAULT 1500.0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Vehicles (Garage)
CREATE TABLE vehicles (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    model TEXT NOT NULL,
    vehicle_type TEXT CHECK(vehicle_type IN ('SCOOTY', 'CAR')),
    battery_capacity REAL NOT NULL,
    current_soc REAL DEFAULT 50.0,
    connector_type TEXT NOT NULL,
    is_primary INTEGER DEFAULT 0,
    FOREIGN KEY(user_id) REFERENCES users(id)
);

-- Stations
CREATE TABLE stations (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    address TEXT NOT NULL,
    city TEXT NOT NULL,
    latitude REAL NOT NULL,
    longitude REAL NOT NULL,
    base_tariff REAL NOT NULL,
    idle_fee REAL DEFAULT 2.0,
    peak_multiplier REAL DEFAULT 1.25,
    rating REAL DEFAULT 4.8,
    host_id TEXT NOT NULL,
    FOREIGN KEY(host_id) REFERENCES users(id)
);

-- Chargers (Bays)
CREATE TABLE chargers (
    id TEXT PRIMARY KEY,
    station_id TEXT NOT NULL,
    identifier TEXT NOT NULL,
    connector_type TEXT NOT NULL,
    power_kw REAL NOT NULL,
    status TEXT CHECK(status IN ('AVAILABLE', 'CHARGING', 'MAINTENANCE', 'FAULTED')),
    current_power REAL DEFAULT 0.0,
    FOREIGN KEY(station_id) REFERENCES stations(id)
);

-- Bookings
CREATE TABLE bookings (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    station_id TEXT NOT NULL,
    charger_id TEXT NOT NULL,
    vehicle_id TEXT,
    slot_time TEXT NOT NULL,
    duration_min INTEGER DEFAULT 45,
    estimated_kwh REAL NOT NULL,
    total_amount REAL NOT NULL,
    status TEXT CHECK(status IN ('CONFIRMED', 'ACTIVE', 'COMPLETED', 'CANCELLED')),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(user_id) REFERENCES users(id),
    FOREIGN KEY(station_id) REFERENCES stations(id),
    FOREIGN KEY(charger_id) REFERENCES chargers(id)
);

-- Payments & Settlements
CREATE TABLE payments (
    id TEXT PRIMARY KEY,
    booking_id TEXT NOT NULL,
    amount REAL NOT NULL,
    platform_fee REAL NOT NULL,
    host_payout REAL NOT NULL,
    payment_method TEXT NOT NULL,
    transaction_ref TEXT UNIQUE NOT NULL,
    status TEXT CHECK(status IN ('SUCCESS', 'PENDING', 'FAILED')),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(booking_id) REFERENCES bookings(id)
);

6.2 REST API Specification

Endpoint Method Description & Parameters
/api/auth/users GET Fetch all registered users and stakeholder profiles.
/api/auth/vehicles GET List vehicles in the driver's garage (?userId=:id).
/api/auth/vehicles/:id/soc PUT Update vehicle battery state of charge (SoC %). Body: { soc: number }.
/api/stations GET Search and filter stations by keyword, connector, power, price, and geo-radius.
/api/stations/:id GET Retrieve detailed station hardware specs, amenities, and bay availability.
/api/stations/:id/tariff PUT Update base tariff, peak multipliers, and idle parking fees (Host only).
/api/bookings/slots GET Generate 45-minute available slot matrix (?stationId=:id&date=:date).
/api/bookings POST Reserve a charging bay with atomic concurrency double-booking prevention.
/api/bookings/active GET Fetch active charging sessions with live metering (?userId=:id).
/api/payments/process POST Process payment with 10% platform / 90% host settlement split.
/api/payments/invoice/:bookingId GET Generate cryptographic GST tax invoice with HMAC-SHA256 signature.
/api/ai/recommend POST Compute multi-factor recommendation score for driver location and vehicle.
/api/ai/trip-planner POST Plan long-distance EV trip with battery discharge curve and charging stops.
/api/telemetry/stream GET Server-Sent Events (SSE) persistent live telemetry broadcast pipe.
/api/telemetry/ocpp/event POST Dispatch simulated OCPP events (StartTransaction, StopTransaction, Fault).
